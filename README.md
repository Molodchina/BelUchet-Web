# BelUchet-Web

Статический клиентский сайт beluchet.ru. Юридические страницы и согласия находятся в `privacy/`, `consent/`, `cookies/` и `disclaimer/`.

Перед публикацией юридических изменений обязательно пройти [чек-лист соответствия](LEGAL-COMPLIANCE.md). Пока в `assets/config.js` не заполнены подтверждённые реквизиты оператора, страницы политики и согласия показывают предупреждение о незавершённой настройке.
