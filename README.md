# BelUchet-Web

Статический клиентский сайт beluchet.ru. Юридические страницы и согласия находятся в privacy/, consent/, cookies/, terms/ и disclaimer/.

Перед публикацией юридических изменений обязательно пройти [чек-лист соответствия](LEGAL-COMPLIANCE.md). Реквизиты и адрес плательщика НПД заполнены. Форма заявки остаётся намеренно заблокированной флагом `legal.personalDataRegistrationReady: false` до уведомления Роскомнадзора и проверки российской инфраструктуры обработки данных.

Подробная последовательность регистрации оператора, проверки FirstVDS/Beget и переноса с GitHub Pages: [docs/PD-RKN-REGISTRATION-GUIDE.md](docs/PD-RKN-REGISTRATION-GUIDE.md).

Внутренний заполняемый шаблон для пилотных клиентов находится в [docs/INDIVIDUAL-CONTRACT-TEMPLATE.md](docs/INDIVIDUAL-CONTRACT-TEMPLATE.md).
